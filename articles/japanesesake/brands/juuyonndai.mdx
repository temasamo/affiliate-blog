# 🍶 十四代とは？
高木酒造（山形県村山市）は、400年以上の歴史を持つ老舗。  
しかし現当主・高木顕統氏が新しい醸造哲学を導入したことで、十四代は“日本酒の革命児”と呼ばれるようになりました。

### 十四代の味わいを支える4つの要素
- **圧倒的な吟醸香**（白桃・メロン・バナナのよう）
- **雑味ゼロの透明感**
- **甘味と旨味の調和**
- **スッと消える優しいキレ**

「華やかで飲みやすい日本酒」の基準を作ったブランドと言っても過言ではありません。

## 🔍 「秘伝玉返し」とは？（必読）
記事で最も重要なポイント。

### ✔ 一般的な本醸造  
醸造アルコールを外部から購入 → すっきりしたキレを演出

### ✔ 秘伝玉返し  
十四代独自の“自家製アルコール製法”  
- 精米歩合の高い米で特別な醪を造る  
- そこから取った**自家製アルコール**を少量だけ加える  
- 純米酒由来の旨味＋本醸造のキレ  
→ **両方の良さを持つ独自ジャンル**

この工程が本丸を「ただの本醸造」ではなく **“十四代の哲学を最も理解できる一本”** に押し上げている。
