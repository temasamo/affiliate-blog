# 業界分析｜港湾荷役機械（外部環境編）

港湾荷役機械は、港湾ロジスティクスを支える大型設備です。

対象には、

- ガントリークレーン
- RTG
- RMG
- AGV
- 自動搬送設備
- 遠隔操作システム
- 港湾制御システム

などが含まれます。

政府資料では、港湾荷役機械は「戦略17分野・先行検討技術【26】」として整理されています。

重要なのは、単なる港湾設備市場ではない点です。

港湾荷役機械は、

- 港湾の国際競争力
- 労働環境改善
- 生産性向上
- 自動化・遠隔操作化
- 特定国依存の低減
- 経済安全保障

と接続しています。

## 主要KPI

- 世界コンテナ取扱量：増加基調
- 日本の港湾荷役機械シェア：約1割程度
- 特定国メーカー：世界市場で圧倒的シェア
- 主要需要：自動化・遠隔操作化・更新投資
- 主要ボトルネック：初期投資、人材不足、保守責任、サイバー対応

## 日本の勝ち筋

日本の勝ち筋は、価格競争ではありません。

重要なのは、

- 信頼性
- 耐震性
- 長期保守
- 港湾運営ノウハウ
- 自動化・遠隔操作化
- 同盟国・同志国市場

です。
