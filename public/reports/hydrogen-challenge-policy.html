CHAPTER 00 課題・政策パッケージサマリー（2026年04月〜05月）
// ANALYST NOTE
水素等の課題は4製品それぞれに固有のボトルネックがあるが、その根底に「供給側は安定した需要が見込めないと投資に踏み込めず、需要側は安定・安価な供給が見込めないと購入契約に踏み込めないというジレンマ」（各種資料）という共通構造がある。この鶏と卵を突破するために、公的支援約4兆円以上が「呼び水」として機能する設計だ。みずほ銀行（2026年3月）の分析では「停滞シナリオでは水素等需要は100万トン未満」という数字が示すように、水素市場の実現は炭素価格水準・再エネコスト低下スピード・各国の政策継続性という3つの外部要因への依存が大きい。各製品の政策パッケージは、この外部要因の不確実性の中で「先行投資の経済合理性を政府支援で補完する」という設計だ。

CHAPTER 01 （1）投資促進に向けた課題
共通課題：供給・需要双方の投資判断の鶏と卵
// ROADMAP
サプライチェーン全体を通じた社会実装に向けた最大の課題は、需要創出と価格低減。
// BOTTLENECK（共通）
水素等の社会実装に向けた最大の課題は「需要創出と価格低減」という二つの問題が相互に依存していることだ。水素価格が高いから需要が生まれず、需要が少ないから大量生産できず、大量生産できないから価格が下がらないという悪循環がある。供給側は「安定した需要が見込めないと能増投資に踏み込めず」、需要側は「安定・安価な供給が見込めないと購入契約に踏み込めない」という双方向の鶏と卵問題だ（各種資料）。
4製品別の課題
ⅰ) 水素アンモニア混焼/専焼タービン
// ROADMAP
供給側は、安定した需要が見込めず能増投資に踏み込めない。需要側は、大規模水素の輸送技術の未確立や燃料価格高騰の影響もあり、投資判断に遅れが生じている。
// BOTTLENECK
日本のガスタービンメーカー（三菱重工・川崎重工・IHI）は水素・アンモニア対応タービンで世界シェア約4割を持つ技術優位があるが、「水素燃料が継続的・安価に調達できる保証がない」という需要側の不確実性から、新設投資判断が遅れている。また大規模水素の長距離輸送技術（パイプライン・液化水素船以外の手段）がまだ確立されていないため、大規模な水素火力発電のサプライチェーン設計が困難な状況だ。
// 官の動き（直近2ヶ月）
  • 長期脱炭素電源オークション：第1・2回で水素換算約25万トンの需要が創出されたが「支援を確保できた電源は一部」という状況（みずほ銀行、2026年3月） みずほ銀行 2026.3
ⅱ) 水電解装置
// ROADMAP
装置の大型化・モジュール化や要素技術の開発・実証、量産体制構築が道半ば。コスト低減が必要。海外を含む市場参入に向け、商用規模のプロジェクト実績蓄積が必要。
// BOTTLENECK
水電解装置の技術開発は世界で加速しており、各国が競い合っている状況だ（各種資料）。日本の強みは「耐久性」「多様方式（アルカリ/PEM/SOEC）での実証経験」だが、コスト競争では欧州・中国の大型装置に対して厳しい状況にある。「商用規模のプロジェクト実績蓄積が必要」という課題は、⑯バイオ医薬品分野の「CDMOの実績の壁」と同じ構造で、実績なしには受注できず、受注なしには実績が積めない悪循環だ。
// 海外動向

欧州 水素銀行構想に基づき、大規模水電解プロジェクトへの補助が進む。欧州市場での実績獲得が日本企業にとっても重要な課題となっている。

ⅲ) 液化水素関連機器
// ROADMAP
運搬技術に加え、受入インフラ（貯蔵やバンカリング）の整備が必要。世界に前例のない取組であり、商用実績が乏しいことから、事業投資判断まで至らない。
// BOTTLENECK
「世界に前例のない取組」という表現が課題の本質を示す。川崎重工等が世界初の液化水素運搬船「すいそふろんてぃあ」の実証に成功したが、受入側のインフラ（陸上タンク・バンカリング設備等）が未整備の状況では商用ビジネスが成立しない。「商用実績が乏しいことから事業投資判断まで至らない」という悪循環は、新しい技術が「実績ゼロから最初の商用案件を得る」という最も難しい段階にある。
ⅳ) 燃料電池
// ROADMAP
①水素インフラ不足/運営費の高さ、②車両価格の高さ、③水素価格の高さの3つ巴の課題から、社会実装で、急伸する中国に遅れ。量産投資による中国製の価格低減。
// BOTTLENECK
「3つ巴」に加えて、中国製燃料電池の量産投資による価格低減という新たな競争圧力が加わる。中国は国家主導で燃料電池バス・トラックの普及を進め、量産効果でコストを下げており、日本製の高性能セルとの価格差が縮まる可能性がある。日本の強み（セル性能の高さ・高耐久性・長寿命）という非価格価値を国際標準や評価基準に反映させることが、単純な価格競争を避けるための重要な戦略となる。
// 海外動向

中国 国家主導でFC商用車（バス・トラック）の普及を推進し、量産効果で燃料電池システムのコスト低減が進んでいる。日本が「重点地域」での集中展開で規模を確保できるかが競争の分かれ目になる。

CHAPTER 02 （2）講じるべき政策パッケージ
ⅰ) ガスタービン：価格差支援×脱炭素電源オークション
// ROADMAP
①国内投資支援：投資判断可能な水準まで技術を確立するためのGI基金の活用等。②需要創出・市場確保・社会実装支援：水素・アンモニア火力を段階的に導入して需要を喚起するため、水素社会推進法に基づく価格差に着目した支援や長期脱炭素電源オークション活用。
// WHY IT MATTERS
「価格差に着目した支援」は、水素・アンモニア燃料と既存の天然ガス・石炭燃料のコスト差（水素・アンモニアの方が高い部分）を政府が補填する制度だ。これにより「水素・アンモニア火力の運転コストが実質的に既存燃料と同等になる」という環境を作り出し、需要側の投資判断を後押しする。鶏と卵問題の「需要側」のコストリスクを政府が負担する設計だ。
ⅱ) 水電解装置：GI基金+GXサプライチェーン+日欧制度連携
// ROADMAP
①国内投資支援：GI基金を活用した、大型化・モジュール化や要素技術開発。コストダウン・シェア拡大のため、GXサプライチェーン構築支援事業を通じた量産体制確立に向けた投資促進。②国際連携・需要創出：水素等の需要国との連携枠組みを効果的に活用した、経済安全保障の観点からの制度設計や、対供給国との交渉力強化・市場拡大のための規格作り等の推進。
ⅲ) 液化水素関連機器：GI基金+国際標準化+需要国連携
// ROADMAP
①国内投資支援：投資判断可能な水準まで技術を確立するためのGI基金の活用等。②国際連携・需要創出：液化水素のローディングアームや液化水素受入基地等の国際標準化。水素等の需要国との連携枠組みを効果的に活用した、経済安全保障の観点からの制度設計や、対供給国との交渉力強化、市場拡大のための規格作り等の推進。
// WHY IT MATTERS
「液化水素受入基地の国際標準化」は、「世界で唯一製造できる日本」という優位性を維持するための重要な施策だ。日本製の受入基地（タンク・ローディングアーム等）の仕様が国際標準になれば、世界中で液化水素を受け入れる際に「日本製設備が必要」という不可欠性が確立する。
ⅳ) 燃料電池：GXサプライチェーン+重点地域指定
// ROADMAP
①国内投資支援：コストダウン・シェア拡大のため、GXサプライチェーン構築支援による、量産体制確立に向けた投資の促進。②需要創出・市場確保・社会実装支援：大規模な商用FCVの需要を創出し、水素ステーションの自立化を促すため、「燃料電池商用車を集中的に導入する重点地域」の指定（燃料費を含む集中支援によるインフラ・車両・荷主の3者の状況を踏まえた需要喚起）。
// WHY IT MATTERS
「重点地域」の指定は3つ巴問題への最もシンプルな解だ。「全国一斉に展開しようとするから3つ巴のジレンマが解けない」という発想の転換で、特定地域にリソースを集中することでインフラ・車両・荷主の相互依存問題を解消する。物流拠点・配送センターが集積する地域を選定すれば、FCトラックの導入台数・水素ステーションの利用頻度・水素消費量が一定水準を超え、水素ステーションの採算が成立する可能性が高まる。
// 官の動き（直近2ヶ月）
  • 「燃料電池商用車を集中的に導入する重点地域」の指定がロードマップ素案の政策パッケージに明記。燃料費を含む集中支援により、インフラ・車両・荷主の3者を同時に支援する設計 ロードマップ素案 2026.3
// 民の動き（直近2ヶ月）
  • トヨタ・本田等：FC商用車（FCトラック）の実証・量産投資を継続中。水素ステーションの大型化・マルチ化（近傍需要への供給拠点）も一部企業が開始 ロードマップ素案 2026.3
